## v0.1.0 — Initial release

**The ARCH/GARCH family from first principles** in pure Python + NumPy/SciPy.
6 modules, ~650 lines, no econometrics library underneath.

Built with the portfolio's **adversarial multi-agent workflow**: a 3-angle
design panel → synthesis into 17 algebraic identities → one refutation agent
per identity (**9 of 17 corrected** BEFORE implementation) → implementation
→ adversarial code review.

### The 6 modules

  - **`garch.py`** — GARCH(1,1) `GARCHParams` (frozen) + the variance filter
    + closed-form moments (unconditional variance, persistence, half-life,
    kurtosis with existence guard, eps² ACF).
  - **`arch.py`** — ARCH(p) + the GARCH(1,1)=ARCH(∞) geometric-weight bridge
    (a second, independent derivation of the GARCH variance).
  - **`gjr.py`** — GJR-GARCH asymmetric leverage; persistence α+β+γ/2; bit-for-bit
    GARCH nesting at γ=0.
  - **`ewma.py`** — EWMA / RiskMetrics as IGARCH(0, 1−λ, λ); geometric kernel;
    λ=0.94 daily / 0.97 monthly.
  - **`likelihood.py`** — Gaussian & Student-t log-likelihood, variance
    targeting, MLE via L-BFGS-B (`MLEResult`).
  - **`forecast.py`** — recursive & closed-form multi-step variance forecast
    + the seeded simulator (returns both the eps and σ² paths).

### Tests — 42/42 passing in ~3.5 s

All algebraic-identity based.  Headline identities:

  - `filter == simulating σ² path` exactly (the swap/lag detector the mean misses)
  - unconditional variance ω/(1−α−β); half-life log(0.5)/log(α+β); kurtosis
    3(1−(α+β)²)/(1−(α+β)²−2α²) with the existence guard
  - **GARCH(1,1) = ARCH(∞)** (constant ω/(1−β), not the unconditional variance)
  - **GJR(γ=0) == GARCH** and **EWMA == IGARCH**, both bit-for-bit
  - Gaussian log-lik = explicit sum; **Student-t → Gaussian** (summed O(1/ν))
  - recursive == closed-form forecast, mean-reverting to σ̄²; IGARCH flat/linear branch
  - variance targeting pins σ̄²; **sim→fit** recovers (α,β)
